# Financial P&L Analysis Dashboard

مشروع تحليل مالي ومحاكاة متكامل مصمم خصيصاً لتعقب الأداء المالي، قياس الإيرادات وهوامش الربح، وتقديم أدوات تفاعلية لاتخاذ القرارات الاستراتيجية.

---

## 🚀 Project Overview (نظرة عامة على المشروع)
* يهدف المشروع إلى دراسة وتحليل الإيرادات، التكاليف، وصافي الأرباح بدقة واحترافية عبر لوحة تحكم تفاعلية متطورة.
* يعتمد على أطر عمل مالية متقدمة لتبسيط قوائم الدخل ومراقبة مؤشرات الأداء الرئيسية (KPIs).

---

## 🛠️ Tech Stack & Tools (التقنيات والأدوات المستخدمة)
* **BI & Visualization:** Power BI Desktop, DAX
* **Data Modeling:** Star Schema, Relationships & Filter Propagation
* **Financial & Simulation:** P&L Structure, What-If Parameters, Time Intelligence
* **Data Processing:** Power Query, Excel
* **Version Control:** Git, GitHub

---

## 🏗️ Data Modeling & Architecture (النمذجة الهندسية وبنية البيانات)
* بدأت رحلة البيانات باعتماد **Fact Tables** واضحة للإيرادات (`Revenue`) والمصروفات (`Expenses`)، وربطها بـ **Dimension Tables** هندسية تخدم طبيعة الحسابات الهرمية لقوائم الدخل (`P&L`) مثل جدول المنتجات (`dProduct`)، جدول الحسابات (`dAccountHeader`)، والجدول الزمني (`Calendar Table`).
* التصميم يعتمد على معمارية **Star Schema** لضمان سرعة الاستعلامات والفلترة بكفاءة عالية وأداء استثنائي.

---

## ⚙️ Core DAX Measures & What-If Logic (المعادلات الحسابية ومنطق المحاكاة)
* **معادلة صافي الدخل والمحاكاة الديناميكية (`INCOME-WTF`):** تم دمج متغيرات **What-If Parameters** مع الإيرادات والتكاليف للتنبؤ بالأرباح لحظياً بناءً على أي تغييرات مفترضة في الكميات أو الأسعار.
* توظيف معادلات **DAX** المتقدمة للتعامل مع حسابات الوقت (**Time Intelligence**) وهيكلة الحسابات الختامية بدقة متناهية.

---

## 📊 Dashboard Sections & Key Modules (أقسام الداشبورد والوحدات الرئيسية)
* **Revenue & Margin Analysis:** متابعة إجمالي الإيرادات، إجمالي الهامش الربحي (**GM**)، ونسب الأداء المئوية موزعة حسب الشهور، الفصول، والأقسام.
* **Income Statement:** عرض شامل ومفصل لقائمة الدخل يوضح الإيرادات، التكاليف، المصروفات التشغيلية، وصافي الدخل، ونسب التشغيل.
* **Financial Simulator:** لوحة محاكاة تفاعلية تتيح لأصحاب القرار تعديل كميات المنتجات، تكاليف الإنتاج، أسعار الوحدات، والمصروفات لقياس التأثير المباشر على صافي الأرباح فورياً.
* **Advanced Tooltips:** نوافذ تحليلية منبثقة تفصيلية تظهر عند المرور على العناصر لتعقب أداء المجموعات وفرق العمل والمؤشرات الشهرية بدقة.

---

## 📋 المشاكل المكتشفة والتوصيات الاستراتيجية (السلبيات والحلول)

| المشكلة المكتشفة (السلبيات) | الأثر على العمل والتجارة | الحل المقترح والتوصية للنمو |
| :--- | :--- | :--- |
| **ارتفاع التكاليف ومصاريف التشغيل** | تؤثر بشكل مباشر على صافي الأرباح وتعرقِل النمو رغم زيادة حجم المبيعات الإجمالي. | مراجعة العقود اللوجستية والاعتماد على الأتمتة لخفض المصاريف الثابتة والمتغيرة (**Costs**). |
| **تكدس المخزن وتعرض المنتجات للتلف** | تجميد السيولة النقدية ووجود منتجات تسجل مبيعات صفرية (**No Sales**). | إطلاق حملات تصفية سريعة للمنتجات الراكدة لتحرير السيولة وإتاحة مساحة للمنتجات الأكثر طلباً. |
| **انخفاض متوسط الفاتورة (`AOV`)** | ضعف الاستفادة القصوى من العميل الحالي وعدم استغلال القوة الشرائية بالكامل. | وضع حوافز شرائية مثل الشحن المجاني المشروط أو الخصومات التراكمية الذكية لرفع قيمة السلة الشرائية. |
| **تركز المبيعات جغرافياً** | ضعف المؤشرات في مناطق معينة وظهور فجوات في التواجد الحقيقي للسوق. | توسيع الخطة التسويقية واستهداف المناطق الواعدة لتقليل الاعتماد على الأسواق الرئيسية فقط. |
